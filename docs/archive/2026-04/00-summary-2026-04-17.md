1. **F-02-1 — XSS in `/dashboard` via error-tracker reflection**
   `src/server/routes/dashboard.ts:189-197` · **S** (~15 min)

   attacker-logged errors into `innerHTML`. Add an `esc()` helper and

2. **F-07-1 — No readiness probe** (same as F-03-1)
   `src/server/routes/health.ts` · **S** (~15 min)

   `SELECT 1` so PM2 actually restarts on PG outage.

3. **F-07-2 — OpenSky worker start-failure silenced + arbitrary 5s delay**
   `src/server/index.ts:113-120` · **S** (~20 min)
   `setTimeout` → dynamic import → caught as `log.warn` (doesn't hit
   Sentry). Promote to `log.error` and decide whether API should
   refuse to serve without the worker.

4. **F-01-2 — `@vercel/node` direct HIGH CVEs**
   `dashboard/package.json` · **M** (~2 hr)

   HIGH CVEs. Prod-exposed when dashboard is served. npm's suggested
